## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/mohammadi77/Karyar-Studio.git
```

Go to the project directory

```bash
cd Karyar-Studio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

---

## 📦 Build

```bash
npm run build
```

Preview production build

```bash
npm run preview
```
